# Study Grove AI 단독 분류 신뢰도 설계

## 목표

사람의 승인 절차나 두 번째 AI 호출 없이, 하루 한 번의 Gemini 응답과 서버의 결정적 검증만으로 학습 기록을 보수적으로 분류한다.

핵심 원칙은 **불확실한 연결을 억지로 확정하지 않는다**는 것이다. 근거가 부족한 기록은 잘못된 주제에 연결하는 대신 `미분류`로 보관한다.

## 분류 입력

- 해당 날짜의 학습 기록 ID, 작성자, 제목, 본문 전체
- 최대 80개의 기존 주제
  - slug와 이름
  - 요약
  - 현재 상태
  - 상위 주제 slug

기존 주제 정보는 새 동의어 주제가 반복 생성되는 문제를 줄이기 위해 제공한다.

## AI 응답 계약

기록과 주제의 연결은 한 항목에 하나의 주제만 담는다.

```json
{
  "note_id": "uuid",
  "topic_slug": "nextjs-app-router",
  "confidence": 0.91,
  "reason": "이 주제로 분류한 설명",
  "evidence_quote": "기록 원문에서 그대로 복사한 연속 문장"
}
```

주제 관계에는 관계를 뒷받침하는 기록 ID를 포함한다.

```json
{
  "source_slug": "nextjs-app-router",
  "target_slug": "authentication",
  "relation_type": "related",
  "confidence": 0.88,
  "evidence_note_ids": ["uuid"]
}
```

## 서버 자동 검증

서버는 AI 응답을 저장하기 전에 다음 조건을 검사한다.

1. 입력에 존재하는 `note_id`만 허용한다.
2. 응답 또는 DB에 존재하는 `topic_slug`만 허용한다.
3. 기록 하나에 최대 3개의 서로 다른 주제만 허용한다.
4. `evidence_quote`를 공백 정규화한 뒤 원문에 실제 포함되는지 검사한다.
5. 근거 문장은 공백 제외 12자 이상이어야 한다.
6. 동일 기록과 동일 주제의 중복 연결을 제거한다.
7. 관계의 근거 기록이 양쪽 주제 중 적어도 하나와 검증된 연결을 가져야 하며, 근거 집합 전체가 양쪽 주제를 모두 포함해야 한다.
8. 검증을 통과하지 못한 기록은 `미분류`에 연결한다.

## 자동 판정 기준

### 기존 주제

- 신뢰도 `0.80` 이상 + 원문 근거 확인: `validated`
- 신뢰도 `0.60~0.79` + 원문 근거 확인: `provisional`
- 신뢰도 `0.60` 미만 또는 근거 불일치: 저장하지 않고 `미분류`

### 새 주제

- 신뢰도 `0.85` 이상 + 원문 근거 확인: `validated`
- 신뢰도 `0.60~0.84` + 원문 근거 확인: `provisional`
- 검증된 서로 다른 기록이 2개 이상 연결되면 주제를 `active`로 자동 승격한다.
- 그 전에는 `suggested`로 표시한다.

### 주제 관계

- 신뢰도 `0.85` 이상
- 양쪽 주제가 당일 검증된 기록 연결을 보유
- 알려진 기록 ID로 양쪽 주제의 근거가 확인됨

위 조건을 모두 만족할 때만 관계를 저장한다.

## 데이터 상태

`note_topics.validation_status`는 사람 검토 상태가 아니라 서버 자동 검증 결과다.

- `validated`: 자동 확정
- `provisional`: 근거는 확인됐지만 신뢰도 또는 반복성이 부족함
- `unclassified`: 유효한 자동 분류가 없음

각 연결에는 다음 값을 저장한다.

- `confidence`: 모델이 반환한 신뢰도. 실제 정확도 수치가 아니라 정렬과 판정 입력으로만 사용
- `reason`: AI 설명
- `evidence_quote`: 원문 인용 근거
- `evidence_verified`: 서버의 원문 포함 검사 결과
- `classifier_version`: 사용한 검증 규칙 버전

## 호출 및 실패 정책

- 정리본과 마인드맵은 기존처럼 하루 한 번의 AI 호출에서 함께 생성한다.
- 동일한 입력 해시는 재호출하지 않는다.
- AI 호출, JSON 형식 또는 자동 검증이 실패해도 기존에 성공한 지식 지도는 유지한다.
- 새 기록 중 분류되지 못한 기록만 `미분류`에 추가한다.
- 자동 재시도는 하지 않는다.

## 신뢰성의 한계

이 구조는 AI의 의미 판단 자체를 사실로 보증하지 않는다. 대신 원문 근거, 참조 무결성, 임계값, 기존 주제 재사용과 반복성을 코드로 강제해 잘못된 연결이 지식 지도에 누적될 가능성을 줄인다.

정확도 수치를 주장하려면 별도의 사람이 라벨링한 평가 데이터가 필요하다. 현재 목표는 정확도 수치가 아니라 **근거 없는 결과를 저장하지 않는 자동 운영**이다.
